# Security Lab Builds & CTF Writeups

This site documents two kinds of hands-on security work.

**Lab builds** are the long-running ones — domain controllers, SIEM pipelines, cloud environments. They take weeks, get torn down and rebuilt, and the interesting parts happen between the steps. Each is documented from architecture through validation, including what broke.

**CTF writeups** are the short, focused engagements — a single box, a single kill chain, worked start to finish, across TryHackMe and HackTheBox.

Different rhythms, same goal: making the work reproducible rather than just finished.

## CTF Writeups

Walkthroughs written to be read alongside an active terminal. Commands appear as they were run, so each step can be reproduced against your own deployed instance.

<Steps>
  <Step title="Deploy the target">
    Start the room or machine referenced at the top of the writeup and connect via VPN or a browser-based attack box.
  </Step>
  <Step title="Work through enumeration">
    Run each command against your instance and compare the output. Differences are normal and usually worth investigating.
  </Step>
  <Step title="Move into exploitation">
    Each step explains why a technique works, not only what to run — read before copying.
  </Step>
</Steps>

<Note>
  Everything here is built in isolated lab environments, and CTF writeups cover retired targets only. Configurations are chosen to make concepts observable, not as production hardening guidance.
</Note>
